# Exercise 001: Add two `i32` values

Write a standalone LLVM IR module that defines this function:

```llvm
define i32 @add(i32 %a, i32 %b)
```

The function should return `%a + %b` using an `add i32` instruction.

## Expected behavior

- `@add(2, 3)` returns `5`.
- `@add(-1, 1)` returns `0`.

## Verification command

```sh
llvm-as -disable-output llvm-training/exercises/001-add.solution.ll
```
