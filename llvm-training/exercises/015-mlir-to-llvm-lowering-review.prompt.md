## BCIR concept being modeled

Model a code-review task for a BCIR lowering pipeline that starts from an
MLIR-like operation stream and emits LLVM IR. Instead of writing a full solution
file, review whether the LLVM lowering preserves BCIR concepts such as claim
field projection, register binding, explicit byte strides, intrinsic wrappers,
and metadata hints.

Review the checked-in pseudo-source in
`015-mlir-to-llvm-lowering-review.candidate.mlir` (shown inline below for
convenience):

```mlir
bcir.claim %c {
  rd = [0, 1], wr = [2], lane = H, stride = mixed,
  ham_hint = { domain = HBM, locality = 3 }
}
%src = bcir.bind.read %c[0]
%dst = bcir.bind.write %c[0]
%v = bcir.load %src[%row, %col] { row_stride_bytes = %rs, element_stride_bytes = 4 }
bcir.store %dst[%row, %col], %v { ham_hint = #bcir.ham_hint<HBM, 3> }
```

Then inspect the checked-in good lowering
`015-mlir-to-llvm-lowering-review.good.ll` as the reference artifact for this
review exercise, or compare it with another candidate generated by a lowering
pass.

## Required LLVM constructs

A good reviewed lowering should contain:

- Struct and nested-array `getelementptr` operations for claim `rd` / `wr` field
  projection.
- Register-table pointer lookup for logical BCIR register IDs.
- Explicit `mul` / `add` byte-offset arithmetic for mixed stride addressing.
- `getelementptr i8` for final byte-addressed memory access.
- Concrete `load` / `store` instructions with appropriate alignment.
- Optional wrapper calls or declarations when a BCIR operation maps to an LLVM
  intrinsic.
- Custom `!bcir.ham.hint` metadata, plus named module metadata if hints must be
  discoverable after lowering.

## Expected observation

`015-mlir-to-llvm-lowering-review.good.ll` should assemble successfully. During
review, the learner should be able to explain whether each BCIR concept from
`015-mlir-to-llvm-lowering-review.candidate.mlir` is represented explicitly in
LLVM IR or intentionally erased as non-semantic lowering detail.

## Optional runtime reference

Use these real runtime files as comparison points:

- `runtime/llvm/bcir_claim_accessors.ll` for claim field projection.
- `runtime/llvm/bcir_ops.ll` for BCIR operation wrappers and byte-offset memory
  operations.
- `runtime/llvm/bcir_prefetch_profiles.ll` for stride-derived address
  computation before an intrinsic call.
- `runtime/llvm/bcir_claim_schema.ll` and `runtime/llvm/bcir_schedule_schema.ll`
  for module-level metadata conventions.
